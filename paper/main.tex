\section{Reference Simulation: Flaw Resilience and Bun JIT Determinism}
\label{sec:refsim}
% =====================================================================

In \code{glitchling.ts}, \code{Glitchling} subclasses the unmodified Creature~\#1 \code{Organism} ($272$ spiking neurons across $14$ regions foraging among $16$ colour$\times$shape sites, $1\text{ tick}=1\text{ sim-minute}$, $2{,}880\text{ ticks}=2\text{ sim-days}$) with four switchable perturbations:
\begin{itemize}[leftmargin=1.6em,itemsep=1pt]
  \item \code{scramble}: site values and availability channels are permuted through a random permutation (re-shuffled every $90$ ticks) with additive Gaussian noise ($\sigma = 0.25$);
  \item \code{leaky}: learned site values decay toward their prior $0.25$ at rate $\lambda = 0.06$/tick (mild v1: $0.02$/tick), with plastic synapses decaying by $0.05\lambda$/tick;
  \item \code{backwards}: all $8$ \code{MOT} neurons read out in reversed order and the chosen site $k\in\{0,\dots,15\}$ is mirrored via $k \mapsto 15 - k$;
  \item \code{misfire}: every $60$ ticks, one site value and $20$ random synapses receive multiplicative Gaussian jolts ($\sigma = 0.30$).
\end{itemize}

\textbf{Discovery of Bun/JSC Concurrent JIT Nondeterminism (\code{F31}).} Earlier one-day jam results (\code{Results v2}, $n=2$ seeds $1$--$2$) appeared reproducible in a single clean check, yet a failing GitHub Actions run revealed that default Bun/JavaScriptCore (JSC) execution depends on background concurrent JIT tier-up timing: $11$ identical runs produced $6$ distinct \code{summary.csv} files, with \code{all}-vs-\code{baseline} foraging ranging from $+7\%$ to $+32\%$ and the hit-rate difference even flipping sign once. Setting \code{BUN\_JSC\_useConcurrentJIT=0} eliminates same-machine JIT variance completely: two simultaneous runs under CPU load produce byte-identical \code{summary.csv} outputs.

\begin{theorem}[Universal Ungar $K=-1$ Poincar\'e-Disk M\"obius Containment]
\label{thm:poincare}

Then unconditionally over $\Z$:
\begin{align}
  D &= (S^2 + u_x v_x + u_y v_y)^2 + (u_x v_y - u_y v_x)^2 \ge 0, \label{eq:mob-sos} \\
  D^2 - (N_x^2 + N_y^2) &= (S^2 - |u|^2)(S^2 - |v|^2) D. \label{eq:mob-gap}
\end{align}
In particular, whenever $u, v$ lie strictly inside the open unit disk ($|u|^2 < S^2$ and $|v|^2 < S^2$), Cauchy--Schwarz gives $D > 0$ (\code{poincare\_mobius\_den\_pos}), and \eqref{eq:mob-gap} yields $|N|^2 < D^2$, proving $|u \oplus v| < 1$ strictly (\code{poincare\_mobius\_preserves\_disk}, strictly in \code{[propext, Quot.sound]}).
\end{theorem}

\begin{proof}[Proof structure]
Equation~\eqref{eq:mob-sos} is the Brahmagupta--Fibonacci expansion of $|S^2 + \bar u v|^2$. Setting $s = S^2$, $a = |u|^2$, $b = |v|^2$, $c = \langle u,v\rangle$, $p = s + 2c + b$, $q = s - a$, direct algebraic factorization gives $N_x^2 + N_y^2 = s(p^2 a + 2pqc + q^2 b) = s D (a + 2c + b)$ while $D - s(a+2c+b) = (s-a)(s-b)$, yielding $D^2 - |N|^2 = D(s-a)(s-b)$. All steps are machine-checked over $\Z$ in \code{HyperbolicAndFlaws.lean}.
\end{proof}
